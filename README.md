# Concept Diagnosis: detecting STEM misconceptions in short student responses

Course project (COMP 365). Classifies a short student response from introductory chemistry or
probability/functions into one of six labels and shows feedback through a small web app.
Three models are compared under the same conditions: a keyword/regex baseline, TF-IDF + logistic regression,
and a fine-tuned DistilBERT.

## Repository layout
```
data/raw/handwritten_test.csv      120 handwritten test responses (20 per label)
data/raw/independent_test.csv      independent test set written by other people (responses + writer initials only)
data/raw/app_tests.csv             30 application test cases (correct / incorrect / off-topic / ambiguous)
data/synthetic/expanded.csv        generated by src/expand_dataset.py 
data/processed/                    train.csv, val.csv, test.csv created by src/preprocess.py
src/labels.py                      the six labels
src/expand_dataset.py              template-based dataset generator (dataset v3, matched correct/wrong pairs)
src/preprocess.py                  cleaning, dedupe, leakage checks, group-aware split
src/baseline.py                    keyword/regex baseline (frozen rules)
src/tfidf_baseline.py              TF-IDF + logistic regression
src/train.py                       DistilBERT fine-tuning and evaluation
src/evaluate_independent.py        scores all three models on the independent test set
src/compare_models.py              paired comparison of the three models on the independent test set
src/app_test.py                    runs the 30 application test cases
app/main.py, app/static/index.html FastAPI backend and web page

```
The fine-tuned model (`models/distilbert-misconception/`, about 250 MB) is not stored in the repository;
`src/train.py` recreates it.

## Reproduce the results
```powershell
python src/expand_dataset.py        # 1. generate the training data (3,083 rows)
python src/preprocess.py            # 2. clean and split: train 2,625 / val 442 / test 120
python src/baseline.py              # 3. keyword baseline on val and test
python src/tfidf_baseline.py        # 4. TF-IDF + logistic regression (about 10 s)
python src/train.py                 # 5. fine-tune DistilBERT (CPU)
python src/evaluate_independent.py  # 6. all three models on the independent test set
python src/compare_models.py        # 7. paired comparison (differences, intervals, sign test)
python src/app_test.py              # 8. 30 application test cases through the app's logic
```
Each script prints its metrics and saves reports, predictions and confusion matrices to `results/`.

| Paper result | Produced by | File |
|---|---|---|

| Validation and test scores, TF-IDF + LR | `tfidf_baseline.py` | `results/tfidf_{val,test}_report.txt` |
| Validation and test scores, DistilBERT | `train.py` | `results/model_{val,test}_report.txt`, `model_metrics.json` |

```powershell

```
Open http://127.0.0.1:8000. Restart the server after retraining; the model is loaded once at startup.

## Settings
- Pretrained model: `distilbert-base-uncased` (Sanh et al., 2019), fine-tuned (not trained from scratch).
- DistilBERT: max length 64, batch size 16, 4 epochs, learning rate 2e-5, seed 42, input prefixed with
  `Student response: `; the best epoch by validation macro F1 is kept.
- TF-IDF + logistic regression: word 1-2 grams plus character 2-5 grams, `C` chosen from {0.3, 1, 3, 10, 30}
  on validation macro F1, seed 42.
- Baseline: ordered regex rules in `src/baseline.py`, frozen after version 2. The test sets were not used to write rules.
- App: confidence below 0.5 is shown as "Not sure"; input without formula-like characters or topic words is declined.
- - Hardware: `Intel Core Ultra 7 256V, 15.7 GB RAM (16 GB laptop, as reported by Windows)`; no GPU was used.
- Key dependency versions: torch 2.14.1, transformers 5.19.0, scikit-learn 1.9.1, pandas 3.0.6, fastapi 0.143.0. The full pinned list is in `requirements.txt`.

## Data
All training and validation data is synthetic, generated by `src/expand_dataset.py`. No public datasets and no
real student data are used. `handwritten_test.csv` was written by the project author. `independent_test.csv`
has 47 responses written by four contributors who each wrote short invented answers from a written handout;
replaced their initials with mine in regards to anonimity. No IRB review applies because no personal information about students is collected.


## Reported results (to check your run against)
Accuracy / macro F1. Validation has 442 rows, the handwritten test set 120, and the independent set 47.

| Model | Validation | Handwritten test | Independent |
|---|---|---|---|
| Keyword baseline (v2) | 0.568 / 0.41 | 0.658 / 0.69 | 0.574 / 0.603 |
| TF-IDF + logistic regression | 0.665 / 0.679 | 0.858 / 0.865 | 0.851 / 0.844 |
| DistilBERT (dataset v3) | 0.731 / 0.764 | 0.858 / 0.858 | 0.787 / 0.784 |

## Known limitations and reproducibility caveats
- Test sets share an author with the generator, so absolute test scores are probably optimistic; see the paper.
- Fine-tuning on a CPU is not bit-for-bit deterministic across machines or library versions, so DistilBERT
  scores can differ slightly from the reported ones. The data generation, preprocessing, baseline, and TF-IDF
  steps are seeded and should repeat exactly.
- The model cannot verify specific facts (for example whether a given conjugate pair is right).
